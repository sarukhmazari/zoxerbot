## 🌟 Key Features

ZOXER BOT is designed to make your WhatsApp experience smarter and more interactive.

- 🤖 **AI Integration**: Chat effortlessly with built-in AI capabilities.
- 🛡️ **Group Guard**: Extreme group management (Admin Lock, Auto-demote, Anti-link).
- 🎬 **Multi-Media**: High-quality YouTube MP3/MP4 downloads and Giphy integration.
- 📥 **Social Downloader**: Fetch content from Instagram, TikTok, and more.
- 🎨 **Sticker Engine**: Convert images, videos, and GIFs into custom stickers effortlessly.
- 🎙️ **Voice Synthesis**: Convert text to multiple languages with the gTTS engine.
- ⚡ **Lightning Fast**: Built on Baileys Socket for ultra-low latency.

## 🛠️ Installation & Setup

### 1. Fork & Clone
```bash
git clone https://github.com/sarukhmazari/MazariBot.git
cd MazariBot
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configuration
- Rename `.env.example` to `.env` (if provided) or configure your `settings.js`.
- Add your **Owner Number** and **Bot Name**.

### 4. Start the Bot
```bash
npm start
```
Scan the QR code printed on your terminal using WhatsApp "Linked Devices".

## ⚙️ Environment Variables

| Variable | Description |
| :--- | :--- |
| `BOT_NAME` | The name of your AI bot |
| `OWNER_NUMBER` | Your WhatsApp number (e.g., 923232391033) |
| `BOT_MODE` | Set to `public` or `private` |
| `BOT_PACKNAME` | The name on your stickers |
