# Antigravity Rules for Zoxer MD

## 🚨 Git & Deployment Safety Rules (Strict Enforcement)

1. **NEVER AUTO-PUSH:**
   - Under NO circumstances should you ever run `git push` automatically.
   - Even if you fix an issue, add a feature, or complete a task, **DO NOT PUSH** without explicit permission.

2. **EXPLICIT USER PERMISSION REQUIRED:**
   - You may ONLY execute `git push` when the user explicitly commands:
     - "push the code"
     - "code push kr do"
     - "push it"
     - or gives direct, unambiguous written approval to push.

3. **CONFIRMATION BEFORE DEPLOYMENT:**
   - Always report completed changes to the user first.
   - Stop and wait for the user to review and confirm before running any deployment or push commands.

## 🗣️ Language & Communication Rules
1. **ALWAYS RESPOND IN ROMAN URDU:**
   - Always provide responses, explanations, and guides in clean Roman Urdu.
